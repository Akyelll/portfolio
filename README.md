# 🚀 Portfólio Front-End — Arte & Desenvolvimento Web

Projeto de portfólio construído com foco em simular um ambiente real de produto front-end, combinando apresentação visual, organização de projetos e experiência de navegação fluida.

O objetivo não foi apenas prática acadêmica, mas a construção de uma base escalável de interface, com padrão próximo ao usado em projetos reais.

---

## 🌐 Acesso ao projeto

- Portfólio principal: https://akyelll.github.io/portfolio/  
- Projeto Barbearia (site comercial): https://akyelll.github.io/Barbearia/  
- Projeto Solar System (interativo): https://akyelll.github.io/solar-system/  

---

## ⚙️ Stack técnica aplicada

- HTML5 semântico e estruturado
- CSS3 avançado (Flexbox, Grid, responsividade e animações)
- JavaScript Vanilla (DOM, eventos e interações de UI)
- Google Maps Embed API
- WhatsApp Click-to-Chat API
- Font Awesome (ícones vetoriais)

Sem frameworks — controle direto da base para aprofundar fundamentos.

---

## 🎯 O que este projeto demonstra

### 📌 Engenharia de interface
- Layout multi-seção com navegação clara e estruturada
- Separação lógica entre áreas (arte e programação)
- Organização de conteúdo como produto, não apenas páginas isoladas

### 🎠 Interação e experiência
- Carrossel infinito implementado em JavaScript puro
- Cards dinâmicos para apresentação de projetos e artes
- Microinterações (hover, brilho e feedback visual)
- Botão flutuante do WhatsApp com animação

### 📱 Responsividade aplicada de forma real
- Mobile-first funcional (até 768px)
- Adaptação para tablets e desktops
- Reorganização estrutural de blocos por breakpoint
- Tipografia ajustada por contexto de tela

---

## 🧠 Decisões técnicas relevantes

- CSS modularizado por responsabilidade (base, seções e componentes)
- Uso de variáveis CSS para consistência visual
- Evitado uso de frameworks para domínio total do DOM
- JavaScript aplicado diretamente para controle de UI e interação
- Estrutura preparada para migração futura (React / Next.js / backend)
